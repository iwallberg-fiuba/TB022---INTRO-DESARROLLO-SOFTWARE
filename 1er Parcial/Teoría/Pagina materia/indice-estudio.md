## Definiciones rapidas

Esta seccion no esta para memorizar palabras sueltas, sino para que sepas que lugar ocupa cada bloque dentro de la materia.

| Keyword | Definicion | Para entenderlo mejor |
| --- | --- | --- |
| `entorno` | Bloque de temas ligados al sistema, la terminal y la base operativa para trabajar. | Es la "base del taller": antes de programar fuerte, necesitas saber en que sistema te moves y como interactuar con el. |
| `herramientas` | Conjunto de utilidades concretas que se usan para desarrollar, versionar o desplegar. | Son instrumentos de trabajo. No explican por si solos la teoria, pero te permiten hacer trabajo real de desarrollo. |
| `desarrollo` | Proceso de construccion de soluciones de software y de aprendizaje de sus practicas. | Aca importan las tecnicas para construir cosas, no solo definiciones sueltas. |
| `datos` | Bloque centrado en almacenamiento, consulta y organizacion de informacion. | Sin esta parte, el software no sabe guardar, recuperar ni relacionar informacion util. |
| `conceptos` | Ideas teoricas que explican por que y como se construye software. | Es el bloque que te da criterio. Sirve para entender decisiones, no solo comandos. |
| `orden de lectura` | Secuencia recomendada para estudiar los apuntes sin perder contexto. | No todos los temas pesan igual al principio. El orden evita estudiar herramientas sin entender la base. |
| `Bash` | Shell y lenguaje de scripting muy usado en Linux y automatizacion. | Es la puerta de entrada al trabajo por terminal y a la automatizacion de tareas repetitivas. |
| `Linux` | Sistema basado en el kernel Linux, clave en servidores y desarrollo. | Aparece en casi toda la infraestructura moderna, por eso condiciona muchas otras herramientas. |
| `Git` | Sistema de control de versiones para registrar y coordinar cambios. | Te permite trabajar sin perder historial y sin depender de "copias finales definitivas ahora si". |
| `Docker` | Plataforma de contenedores para ejecutar apps en entornos reproducibles. | Ayuda a que una app corra de forma mas parecida en distintas maquinas. |
| `SQL` | Lenguaje para consultar y manipular bases de datos relacionales. | Es la forma clasica de hablar con la informacion persistida de una aplicacion. |
