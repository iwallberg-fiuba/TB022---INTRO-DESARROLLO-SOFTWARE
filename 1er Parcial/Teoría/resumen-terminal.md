## Idea central

La terminal es una interfaz de texto para comunicarse con la computadora. En el contexto del curso, aparece como herramienta esencial porque permite automatizacion, administracion y trabajo tecnico rapido.

## 1. Que es una terminal

- interfaz textual,
- recibe comandos escritos,
- permite operar sin interfaz grafica.

Tambien se habla de:

- consola,
- linea de comandos,
- CLI.

## 2. Un poco de historia

- en decadas pasadas se usaban teletypes,
- luego terminales de texto,
- hoy usamos emuladores modernos de esas terminales.

## 3. Terminal vs shell

### Terminal

Es la ventana o programa visual que muestra texto.

Ejemplos:

- GNOME Terminal,
- iTerm2,
- Windows Terminal.

### Shell

Es el interprete que entiende comandos.

Ejemplos:

- Bash,
- Zsh,
- Fish.

### Regla de memoria

- terminal = envoltorio,
- shell = cerebro.

## 4. Para que sirve

- automatizar tareas,
- administrar servidores,
- instalar software,
- usar Git,
- compilar y ejecutar programas,
- resolver tareas mas rapido que con GUI.

## 5. Por que aprenderla

- se usa a lo largo de la carrera,
- es central en el mundo laboral,
- da control fino sobre la maquina,
- es parte de la alfabetizacion tecnica de un desarrollador.

## 6. Comandos esenciales

- `pwd`: directorio actual.
- `ls`: listar archivos.
- `cd`: cambiar directorio.
- `mkdir`: crear directorio.
- `touch`: crear archivo vacio.
- `cat`: mostrar contenido.
- `cp`: copiar.
- `mv`: mover o renombrar.
- `rm`: eliminar.
- `man`: manual.

## 7. Tips utiles

- `Tab`: autocompletado.
- flechas arriba/abajo: historial.
- `Ctrl + C`: cancelar.
- `Ctrl + L`: limpiar pantalla.
- `--help`: ayuda de muchos comandos.
