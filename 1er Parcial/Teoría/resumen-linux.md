## Idea central

Linux es presentado no como "otro sistema operativo mas", sino como el kernel que sostiene una enorme parte de la infraestructura informatica moderna.

## 1. Mensaje fuerte del material

Linux esta en todos lados:

- supercomputadoras,
- infraestructura cloud,
- Android,
- Chrome OS,
- servidores web,
- sistemas embebidos,
- y cada vez mas escritorios tecnicos.

## 2. Linux no es distro

### Linux

Es el kernel.

### Distro

Es un sistema construido sobre el kernel Linux, con herramientas, gestor de paquetes, entorno y filosofia propia.

### Idea importante

Confundir Linux con distro es como confundir motor con vehiculo completo.

## 3. Antecedentes historicos

### Unix

- Bell Labs,
- Ken Thompson,
- Dennis Ritchie,
- origen del universo Unix-like.

### GNU

- proyecto de Richard Stallman,
- introduce copyleft y GPL,
- produce herramientas esenciales como GCC, Bash, GDB y Emacs,
- buscaba un sistema tipo Unix libre.

### Linux

- proyecto de Linus Torvalds en 1991,
- kernel Unix-like libre,
- combinado con herramientas GNU forma un sistema operativo funcional.

## 5. Opciones de instalacion

### Instalacion nativa

- recomendada,
- mejor performance,
- entorno completo,
- mas invasiva.

### WSL2

- aceptable,
- bastante performante,
- terminal Linux dentro de Windows,
- facil para Docker,
- seguis sobre Windows.

### Maquina virtual

- menos invasiva,
- facil de instalar,
- peor performance,
- menos comoda para trabajo serio,
- el material la marca como no recomendada.

- Unix y GNU son antecedentes clave.
