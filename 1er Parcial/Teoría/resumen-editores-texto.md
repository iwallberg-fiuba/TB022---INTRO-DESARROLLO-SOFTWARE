## Idea central

El editor de texto es la herramienta fundamental del desarrollo porque el codigo fuente y muchos archivos de configuracion viven en texto plano.

## 1. Que es un editor de texto

- programa para crear y modificar texto plano,
- no agrega formato oculto,
- lo que ves es lo que realmente hay en el archivo.

## 2. Por que importa el texto plano

- es el formato natural del codigo,
- evita metadatos invisibles,
- es simple, portable y liviano,
- facilita control de versiones y automatizacion.

## 3. Historia resumida

- `ed` (1969): editor de linea.
- `vi` (1976): primer editor visual de terminal.
- `Emacs` (1976): muy extensible.
- `Vim` (1991): evolucion de `vi`.

### Lectura importante

La longevidad de estas herramientas muestra que editar texto es una necesidad estructural del trabajo tecnico.

## 4. Editor de texto vs procesador de texto

### Editor

- texto plano,
- sin formato oculto,
- liviano,
- ideal para codigo, scripts y configuracion.

### Procesador

- formato enriquecido,
- estilos, fuentes y metadatos,
- pensado para documentos e informes,
- menos apto para codigo fuente.

## 5. Herramientas nombradas

### Vim / Neovim

- modal,
- centrado en teclado,
- muy rapido,
- corre en cualquier terminal.

### VS Code

- interfaz grafica moderna,
- extensible,
- enorme ecosistema,
- integracion fuerte con herramientas modernas.

### Zed

- performance nativa,
- escrito en Rust,
- colaboracion en tiempo real.

### Nano

- simple,
- amigable,
- corre en terminal.

## 6. Que es un IDE

Un IDE va mas alla de un editor:

- autocompletado inteligente,
- navegacion de codigo,
- debugger,
- integracion con Git,
- compilacion y ejecucion integradas.

## 8. Memorizacion rapida

- Editor = texto plano.
- Procesador = texto con formato.
- Codigo se escribe en editores.
- IDE = editor + herramientas de desarrollo integradas.
