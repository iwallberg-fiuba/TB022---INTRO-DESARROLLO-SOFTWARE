# INICIO

<br>

Este archivo contiene enlaces a todo el material necesario para cursar y aprobar el parcial de:<br>
[TB022 — Introducción al Desarrollo de Software](https://www.intro-camejo.com.ar/) - FIUBA - Cátedra Camejo - 1C26 <br>

<br>

#### Por cada tema, se incluye:

- [Bases](#bases) - el contenido original a estudiar.
- [Interpretado](#interpretados) - resúmenes, diagramas, prezis, etc. hechos a partir del contenido original.
- [Autoevaluación](#autoevaluación) - preguntas, ayudas, plataformas online gratis para practicar cómodamente, etc. para autoevaluarse.
- [Guías](#guías) - consignas y soluciones.
- [Parciales](#parciales) - parciales anteriores y soluciones.
- [Extra Docs](#extra-docs) - documentación extra sobre el tema en internet.
- [Siempre útiles](#siempre-útiles) - plataformas que **siempre** van a ser útiles.

<br>Si falta algún recurso para cierto tema, es porque está pendiente o no se encontró todavía. <br>

<br>

### Plan de estudio
> La idea es aprender el contenido interpretado (escuchándolo o leyéndolo), pasar a leer los recordatorios, hacer los quizzes y responder las preguntas que se puedan. Anotar las que no. Con ellas, volver al contenido   interpretado y repetir el proceso las veces que sea necesario. Usar el random picker cuando se quiera (considerar que incluye preguntas que requieren conocimiento práctico, pero no la resolución completa de un        problema mediante código). Finalmente, usar las plataformas para practicar y realizar las guías de cada tema.<br>

<br>


#### Parcial - Temas Excluidos
- de SQL, no se tomaron ejercicios con `GROUP BY`, `HAVING` o las funciones de agregación `SUM`, `AVG`, etc.
- de Github, configurar SSH Keys no.
- Nada de frontend (HTML, CSS, JavaScript)
- Nada de backend (Node.js)
