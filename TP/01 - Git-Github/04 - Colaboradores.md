### Colaboradores

<br>

El dueño del repo debe (desde Github) agregar las cuentas deseadas:

```text
Settings
↓
Collaborators
↓
Add people
```

<br>

---

<br>

Los colaboradores deben:

<br>

1. Descargar e instalar git e IDE
2. Poner su mail para git
3. Configurar su SSH de conexión de Git con Github (no de repos)
4. Aceptar la invitación para colaborar en el repositorio (desde Github)
5. Clonar el repositorio `git clone git@github.com:usuario/mi-proyecto.git`

<br>

Y ya podrán trabajar normalmente con comandos como:

```shell
git pull
git add .
git commit -m "mensaje"
git push
```
