### Configurar Git

<br>

Iniciar sesión en Git (única vez)
1. Click derecho en cualquier lugar, abrir Git Bash
2. Escribir los siguientes comandos:

```shell
git config --global user.name "tu-nombre"
git config --global user.email "tu-mail@email.com"
```
