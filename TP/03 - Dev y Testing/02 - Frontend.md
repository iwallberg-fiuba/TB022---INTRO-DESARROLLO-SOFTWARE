
Recordar tipos de testeos porque vamos a hacer los testeos de unidad mientras se desarrolla el frontend.

Para el backend es (cuando esté cada paso de testeo totalmente aprobado y terminado -> vas al siguiente paso):
1. de unidad 
2. de integracion
3. de sistema
4. e2e
5. UAT

| Tipo                         | Qué prueba                                                           |
| ---------------------------- | -------------------------------------------------------------------- |
| **Unit Testing**             | Una función, método o componente aislado.                            |
| **Integration Testing**      | La interacción entre varios módulos o servicios.                     |
| **System Testing**           | El sistema completo funcionando como un todo.                        |
| **End-to-End (E2E)**         | El flujo real del usuario de principio a fin.                        |
| **Acceptance Testing (UAT)** | Verifica que el sistema cumple los requisitos del cliente o usuario. |
