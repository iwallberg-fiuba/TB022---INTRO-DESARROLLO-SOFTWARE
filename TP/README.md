Tools y lenguajes
- Se permite usar cualquier otra tecnología, herramienta o lenguaje, siempre que su propósito esté correctamente definido y justificado en el TP, y se pueda defender en el oral.

Frontend
- HTML y CSS
- JavaScript

Backend
- Node.js
- REST API (Representational State Transfer Application Programming Interface): forma común de diseñar APIs HTTP donde el backend expone recursos/datos mediante URLs y métodos como `GET`, `POST`, `PUT` y `DELETE`.

Ejemplos:
- `GET /usuarios` → obtener usuarios
- `POST /usuarios` → crear usuario
- `PUT /usuarios/5` → modificar usuario
- `DELETE /usuarios/5` → eliminar usuario

Bases de datos
- SQL. Motor: PostgreSQL, utilizando un contenedor Docker basado en la imagen oficial de PostgreSQL.
